    Native persona hooks

    Maps to darkstr.nativePersonaHooks. Off by default. On the darkstr fork, this Settings toggle is authoritative for chrome/C++ hooks.

    Delay persona one page

    Maps to darkstr.strictFirstDoc. Helps sites that break when the persona starts too early. Does not change mode.

    Browser / about:config names (read-only)

    On the darkstr fork, Settings writes these chrome / about:config keys (same names). On stock LibreWolf they remain in browser.storage.local.

    KeyTypeLegal / default
    darkstr.mode string homogeneous \| pollution · default homogeneous
    darkstr.nativeCompatible bool default false
    darkstr.nativeCompatSites JSON object domain map · default {}
    darkstr.strictFirstDoc bool default true (“Delay persona one page”)
    darkstr.nativePersonaHooks bool default false (Native persona hooks · Advanced / fork)

    Related browser prefs (user / fork-managed, not rewritten by the stock WebExt): privacy.resistFingerprinting, privacy.fingerprintingProtection.

    Fork builds · patches apply

    export DARKSTR_GECKO_ROOT=/path/to/librewolf-based-tree
./patches/scripts/apply-darkstr-patches.sh
