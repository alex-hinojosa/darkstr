Two modes. XOR. Never stacked.

LibreWolf Resist Fingerprinting (RFP) makes everyone look the same. Duppel’s pollution engine makes a coherent different persona. Running both at once creates lie-detection contradictions and is refused.

Choose a mode

Pollution requires RFP off

  1. Open about:config in this LibreWolf profile.
  2. Set privacy.resistFingerprinting to false.
  3. Set privacy.fingerprintingProtection to false (do not leave FPP on as a silent stack).
  4. Restart LibreWolf, reload this page, then continue.

LibreWolf maintainers warn that customizing RFP metrics makes you unique and hurts the anonymity set. Pollution is a different product: we turn RFP off rather than tweak it.

Native-Compatible is independent

Banking, SSO, and high-posture sites can break under a spoofed persona. Native-Compatible restores native identity behavior without changing your mode. It is not a Cloudflare-defeat switch.

Site access

Firefox treats host permissions as revocable. Pollution needs access to websites for DNR, scripting, and the later Duppel port.
